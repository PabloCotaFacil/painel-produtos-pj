# Painel de Apoio Operacional — Produtos PJ (CotaFácil)

Hub de conhecimento, manuais operacionais, videoaulas e esteiras bancárias para os **Produtos PJ** (Capital de Giro, Antecipação de Recebíveis, Financiamento PJ e mais).

## Tecnologias
- **Next.js 14** (App Router)
- **React 18** + **Tailwind CSS**
- **Prisma ORM** + **PostgreSQL** (Supabase / Neon)
- Suporte a Modo Claro e Modo Escuro
- Sistema de Busca Inteligente multi-termos
- Feed de Pílulas Verticais (9:16) & Treinamentos Widescreen (16:9)
